# WattWise: Household Energy Consumption Analysis and Peak-Load Prediction

Machine-learning analysis of one household's electricity use (UCI *Individual Household Electric Power Consumption* dataset): exploratory analysis, next-hour load regression, peak-hour classification, clustering of daily profiles, sequential models and tree ensembles.

Course project for 21CSC305P Machine Learning, SRM Institute of Science and Technology, Kattankulathur (Team 4).
